# Los juegos de Joaquín

Serie de tres juegos en Scratch de la materia **Informática Educativa II** (Profesorado Superior de Informática).

- **El Joaquín Pregunta**: trivia Sí / No, 3 niveles.
- **Joaquín Juega**: cabecear globos con la cámara, 3 niveles.
- **Joaquín Ataja**: patear penales con la cámara, 3 niveles.

La página `index.html` reproduce los juegos dentro del sitio, con la cámara real. Si la cámara no está disponible, los juegos se pueden jugar con el mouse.

## Carpetas

- `juegos/`: archivos `.sb3` de cada juego (se abren en Scratch con Archivo › Cargar desde tu computadora).
- `pdf/`: explicación de los bloques de cada juego.
- `embeds/`: diagramas de flujo.
